# Proyecto de Cálculo e Integración Numérica en Python

Este proyecto proporciona un conjunto de herramientas en Python para calcular:

- ✔️ Integrales definidas entre funciones  
- ✔️ Volúmenes de revolución (método de discos/anillos)  
- ✔️ Longitud de curvas  
- ✔️ Longitud comparativa entre dos funciones  
- ✔️ Soporte para integración en eje **X** o eje **Y**  
- ✔️ Funciones matemáticas personalizadas  
- ✔️ Uso de métodos numéricos (Simpson)

El objetivo es facilitar cálculos avanzados de cálculo diferencial e integral utilizando librerías científicas.

---

## 🚀 Características principales

### 🔸 Integrales entre funciones
Permite calcular el área encerrada entre dos curvas usando la regla de Simpson.

### 🔸 Volumen por revolución
Gira funciones alrededor de los ejes **X** o **Y**, con control del eje de rotación.

### 🔸 Longitud de curvas
Calcula la longitud de una función usando derivadas numéricas.

### 🔸 Soporte de funciones personalizadas
Puedes ingresar cualquier función Python que acepte `numpy arrays`.


📦 Instalación

Asegúrate de tener Python 3.10+ instalado.

1. Clona el repositorio:
- git clone https://github.com/LichtSebas/ProyectoDeMatematicaIntegrales

2. Entra al proyecto:
- cd ProyectoDeMatematicaIntegrales

3. Instala las dependencias:
- pip install -r requirements.txt
